# Data Model: Update Hero Section

## Overview
As this project is a static HTML update for a Hero section, there is no formal data model or database schema involved. The "data" consists of static content embedded within the HTML document.

### Static Entities
- **Hero Title**: User's Name
- **Hero Subtitle**: Skills and professional roles
- **Call-to-Action Links**: URLs to PDF CV and contact section
- **Social Links**: External URLs pointing to LinkedIn, GitHub, etc.
- **Profile Image**: Source path to the user's photograph.
