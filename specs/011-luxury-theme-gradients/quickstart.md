# Quickstart: Luxury Theme Gradients

## Overview
This feature introduces subtle, CSS-based gradient backgrounds for both light and dark themes to enhance the "Quiet Luxury" aesthetic of the portfolio.

## Development Setup

1. Open `index.html`.
2. Locate the global CSS custom properties (`:root` and `[data-theme="dark"]`).
3. Modify or introduce the background-related CSS variables.
4. Update the `body` or a dedicated background element to utilize these gradients.

## Testing

- Open `index.html` in a modern browser.
- Toggle between light and dark modes.
- Verify that the background presents a smooth gradient.
- Verify scrolling performance is unaffected (no lagging or repaints).
- Verify text contrast remains accessible (WCAG AA).
