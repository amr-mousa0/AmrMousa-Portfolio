# Quickstart: Testing Egyptian Localization

1. Ensure `translations.js` is included in `index.html`.
2. Open `index.html` in a local server (e.g., `npm run dev` or Live Server).
3. Click the Language Toggle button in the navbar.
4. Verify the cinematic loader activates for 500ms.
5. Verify the text changes to Egyptian Arabic (e.g., "مصمم معماري وديكور داخلي").
6. Verify "Mohammed Wagdy" remains unchanged.
7. Verify layout shifts to RTL gracefully.
