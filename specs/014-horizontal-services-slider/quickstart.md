# Quickstart: Horizontal Services Slider

## Development Flow

1. Update `src/components/astro/ServicesGrid.astro` layout to support `overflow-x: auto` and `scroll-snap`.
2. Introduce scroll control buttons (Left/Right) natively using inline JS inside Astro, or rely purely on trackpad/touch scrolling depending on design preferences.
3. Test locally with `npm run dev` by navigating to the Services section and verifying horizontal scroll momentum on different devices.
